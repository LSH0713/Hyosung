일상 점검

변압기 일상 점검 가이드

📋 점검 개요

-부속기기 점검은 변압기의 안전한 운영을 위해 필수적인 점검입니다.

-냉각장치, 방습장치, 보호계전기 등 각종 부속기기의 정상 동작 여부를 확인합니다.

-매일 동일한 시간에 수행하며, 이상 징후 발견 시 즉시 담당자에게 보고해야 합니다.

⚠️ 주의사항

1. 안전 수칙: 점검 시 반드시 안전모, 절연장갑 착용

2. 기록 관리: 모든 점검 결과는 점검표에 기록하고 이상 발견 시 즉시 보고

3. 정기 교체: 실리카겔은 변색 즉시 교체, 냉각팬 필터는 월 1회 청소

4. 안전거리: 충전부로부터 안전거리 유지 (특고압 2m 이상)

5. 날씨 고려: 우천 시 절연 상태 특별 점검, 강풍 시 부싱 오염도 증가

6. 긴급 조치: 심각한 누유 발견 시 즉시 운전 중지 및 보고

쿨링팬

▼

• - 냉각팬 정상 회전 확인
• - 이상 소음 및 진동 점검

📋 상세 점검 요소
  • 냉각팬 전원 공급 상태 확인
  • 팬 회전 방향 및 속도 확인
  • 날 청결 상태 및 파손 여부 점검
  • 이상 소음 및 진동 측정

호흡기 방습장치

▼

• - 실리카겔 색상 변화 확인
• 청색→분홍색 변색 시 교체

📋 상세 점검 절차
  • 실리카겔 색상 확인
    (청색: 정상, 분홍색: 교체 필요)
  • 호흡기 케이스 외관 손상 점검
  • 오일씰 부위 누유 여부 확인
  • 공기 흡입구 막힘 여부 점검
  • 호흡기 내부 수분 응축 상태 확인
  • 호흡기 연결부 체결 상태 점검

온도계

▼

• - 온도 지시값 정상 범위 확인
• - 경보 접점 동작 시험

📋 상세 점검 절차
  • 절연유 온도 지시값 확인
    (정상 범위: 60~80℃)
  • 권선 온도 지시값 확인
    (상부유온 대비 +10~15℃)
  • 권선 온도가 절연유보다 높아야 함
  • 온도계 표시면 습기 확인
  • 경보 접점 설정값 확인
    (일반적으로 85℃)
  • 트립 접점 설정값 확인
    (일반적으로 95℃)
